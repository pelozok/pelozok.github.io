## About

A bilingual single-page CV for a software engineer who builds with AI. The hero draws the career as a node graph: education and finance feed WordPress, Rails and React, which feed APIs, infrastructure and testing, which converge on applied AI and Finwaise, with "your team" as the next node. Below: skills by category, the Finwaise case, every project grouped, experience and credentials, contact.

## Tech stack

Intentionally lightweight: no framework, no runtime dependencies, no third-party requests.

- **HTML5** with inline SVG canvases (crawlable links, readable without JS).
- **CSS** with custom properties; light and dark via `prefers-color-scheme`.
- **Vanilla JS** only to light a node's neighbourhood on hover/focus.
- **Geist** and **Geist Mono**, self-hosted (`assets/fonts/`).
- **GitHub Pages** for hosting.

## Structure

```

├── _config.yml           # keeps docs and scripts out of the published site

    ├── js/main.js
    ├── fonts/

```

## SEO

- Separate static URLs per language (`/` and `/en/`) with self-canonical and `hreflang` (es, en, x-default), mirrored in `sitemap.xml`.
- JSON-LD `@graph` with `WebSite`, `ProfilePage` and `Person` (`sameAs` LinkedIn and GitHub).
- Open Graph and Twitter cards with a 1200x630 image.
- After deploying: add the site to Google Search Console (HTML tag method), submit `sitemap.xml`, and link the site from the LinkedIn and GitHub profiles.

## Security

GitHub Pages cannot set HTTP headers, so each page ships a strict CSP as a `<meta>` tag: everything is `'self'`, no inline scripts or styles, `base-uri` and `form-action` locked. `frame-ancestors` cannot be set from a meta tag.

## Editing content

All copy (both languages), the graph nodes and the project list live in `scripts/build_pages.py`. Edit it and regenerate:

```bash
python3 scripts/build_pages.py
```

This rewrites `index.html`, `en/index.html` and the geometry block at the end of `styles.css`. Bump `TODAY` in the script and `lastmod` in `sitemap.xml` when content changes.

### CV (PDF)

The one-page CVs (`assets/files/Kevin-Pelozo-Retamar-CV-2026.pdf` in English and `-ES.pdf` in Spanish) are built from `scripts/build_cv.py` with headless Google Chrome. It shrinks the font until each fits on one page:

```bash
python3 scripts/build_cv.py
```

## Running locally

```bash
python3 -m http.server 4173
# open http://localhost:4173
```

Use a server rather than opening the file directly: asset paths are root-relative.

Pushing to `main` publishes the site.
